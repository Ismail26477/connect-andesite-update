# 🎯 Run Your App NOW! (Copy & Paste)

## 5 Minute Setup

### In VS Code Terminal:

```bash
npm install
```

Wait for "added XXX packages"

Then:

```bash
npm run dev
```

You'll see:
```
➜  Local:   http://localhost:5173/
```

### Open Browser:

```
http://localhost:5173/
```

Done! ✅
